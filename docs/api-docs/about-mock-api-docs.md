# About the Mock API documentation

The Mock API documentation demonstrates my general technical writing style and showcases my experience in writing clear, developer-focused API documentation. This documentation is not designed to be extensive or 100% factually correct, instead focusing on demonstrating good practice through the inclusion of key topics and information types only.

The Mock API is a fictional REST API created just for this documentation. It is designed to mimic a simple, fintech API that allows you to make requests around payment transactions.

::: tip AUTHORING APPROACH

The following decisions were made before creating the documentation:

- To ensure clarity, for the purposes of this documentation, Postman is used as the tool of choice for working with the API, and in the provided examples.

- Screenshots are not used.

- It is assumed that users are using the Windows operating system.

In real, customer-facing documentation, the above decisions would differ, but for the sake of time and simplicity, the described approach is taken.

:::

::: tip HOW WAS THIS DOCUMENTATION CREATED?

The Mock API documentation was created using Markdown and the VitePress static site generator, including a custom theme CSS file.
