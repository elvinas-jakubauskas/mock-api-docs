# First steps

This section describes the prerequisite steps you must complete before you can start using the Mock API.

You must do the following:

1. [Install Postman](#downloading-postman)
2. [Create an API key](#creating-an-api-key)

## Installing Postman

Postman is the recommended way of interacting with the Mock API. You must create an account and install Postman onto your local machine before you can start using the API.

::: tip POSTMAN ACCOUNT
A Postman account is not compulsory to interact with the API, but it is recommended.

With a Postman account, you can do the following:

- Organise your work in workspaces
- Sync Postman data across devices
- Back up your Postman data to the cloud
:::

**To create a Postman account:**

1. In your web browser, go to https://www.postman.com/.
2. In the top-right corner, select **Sign Up for Free**.
3. In the **Create Postman account** section, do the following:   
   - In **Work email**, enter your work email.
   - In **Username**, enter a username.
   - In **Password**, enter a password.
4. Select **Create Free Account**.

After you create your account, you can install Postman onto your local machine.

**To install Postman:**

1. In your web browser, go to https://www.postman.com/.
2. Under **Download the desktop app for**, select the Windows icon.
3. On the **Download Postman** page, select **Windows 64-bit**.   
Postman begins downloading.
4. When the download is finished, go to your browser's download library, and select the Postman EXE file.   
Postman opens with the login screen displayed.
5. On the Postman login screen, select **Log In**.   
A browser window opens.
6. In **Email or username**, enter your email or username.
7. In **Password**, enter your password.
8. Select **Sign in**.   
You are signed in and redirected to the Postman desktop application.

## Creating an API key

For authentication purposes, you must create an API key and use it when sending API requests with the Mock API. You can create an API key in our Mock Software Portal.

**To create an API key:**

1. In your web browser, go to https://www.mocksoftwareportal.com.
2. On the dashboard, select **API keys**.
3. On the **API keys** page, select **Create new API key**.
4. In the **Create new API key** popup, do the following:   
   - In **Nme**, enter a name for the API key.
   - In **Expiry date**, select the expiry date of the API key.
   - In the **Permissions** section, select the permissions for the API key.
5. Select **Create**   
The API key is created.
